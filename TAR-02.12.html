Estructura básica de una página HTML

Los elementos fundamentales de una página HTML son:

  • HTML
    • Etiqueta: <html>
    • Elemento principal raiz de HTML
    • Todo el contenido de la página esta aqui incluido
  • HEAD
    • Etiqueta <head>
    • Contiene el título de la página y sus metadatos
  • BODY
    • Etiqueta <body>
    • Contiene el cuerpo de la página
    • Es la etiqueta que se ve en el visor web todo lo que pongas

Etiquetas relacionadas con texto

Algunas etiquetas usadas para el texto son:

  • Párrafo
    • Etiqueta: <p>
    • Usada para introducir un párrafo dentro del cuerpo
    • Los espacios en blanco de esta etiquetas son unicos (3 espaciados se verán como 1)
  • Encabezados
    • Etiqueta <h1>, <h2>...
    • Se usa para poner títulos encabezados dentro del cuerpo
    • Tienen distintos tamaños dependiendo del numero el 1 es el tamaño mas grande y disminuyendo.
  • Salto de línea
    • Etiqueta <br>
    • Se usa para realizar un salto de línea quedando esta vacía
    • Es una etiqueta que no se cierra
  • Texto en Negrita
    • Etiqueta <b>
    • Se usa para resaltar un texto entero o en una parte concreta en negrita
  • Texto en cursiva
    • Etiqueta <i>
    • Se usa para resaltar un texto entero o una fracción en cursiva
  • Texto marcado
    • Etiqueta <mark>
    • Se utiliza para poner un fondo al parrafo o parte concreta

Imágenes y enlaces

Las etiquetas usadas para las imagenes y/o enlaces son:

  • Imágenes
    • Etiqueta: <img>
    • Usada para meter una imagen en la página web
    • Se puede pasar tanto por archivo indicando su ruta como por enlace directo de google.
  • Enlace
    • Etiqueta: <a>
    • Usada para meter un enlace en la página web
    • Se puede enviar dentro de la misma pestaña o redirigir en otra pestaña con el atributo "_blank".
  • Figura
    • Etiqueta: <figure>
    • Usada para añadir una figura en html
    • Se usa también la etiqueta <figcaption> para añadir un pie de texto a la figura.

Listas y Viñetas

Algunas de las etiquetas usadas para las listas y viñetas son:

  • Listas Ordenadas
    • Etiqueta: <ol>
    • Usada añadir una lista ordenada en un html
    • Tiene variaciones pudiendo cambiar la tipografía de los numeros incluso a romanos
  • Listas no ordenadas
    • Etiqueta: <ul>
    • Usada añadir una lista no ordenada en un html
    • Tiene variaciones pudiendo cambiar el tipo de viñeta que usa desde puntos a cuadrados...
  • Elemento de una lista
    • Etiqueta: <li>
    • Usada añadir un elemento a cualquier lista de html

Estilos en HTML

Algunos atributos para los estilos son:

  • Centrado
    • Atributo: <align="lado">
    • NO es una etiqueta si no atributo de ellas
    • Dentro de este atributo se puede alinear a la izquierda, derecha o centrado.
  • Style
    • Atributo: <style>
    • Este atributo es de los mas usados en HTML ya que es el que hace que se vea bonito
    • Este atributo puede contener distintos tipos como el "background-color" que cambia el color del fondo de la página
